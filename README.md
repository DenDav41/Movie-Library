# Movie Library - Библиотека фильмов

**Автор:** Давыдов Денис Андреевич
**Дата выполнения** 04.05.2026

## Описание

Десктопное GUI-приложение для управления персональной библиотекой фильмов с возможностью добавления, фильтрации и сохранения данных. Разработано на Python с использованием библиотек `tkinter` и `json`.

### Основной функционал:

- ✅ **Добавление фильмов** с указанием названия, жанра, года выпуска и рейтинга
- ✅ **Валидация данных**:
  - Год - только целое число (1888-2026)
  - Рейтинг - число от 0 до 10
  - Название не может быть пустым
- ✅ **Фильтрация**:
  - По жанру (9 предустановленных жанров)
  - По году выпуска
- ✅ **Сохранение и загрузка** данных в/из JSON файла
- ✅ **Удаление** фильмов из библиотеки
- ✅ **Статистика**:
  - Общее количество фильмов
  - Средний рейтинг
  - Самый популярный жанр
  - Лучший фильм по рейтингу
